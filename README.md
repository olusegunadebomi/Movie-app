## Vite migration & local development

This project was migrated from Create React App to Vite (faster dev server and smaller build output).

Common tasks:

```bash
# install deps
npm install

# start dev server (hot reload)
npm run dev

# build for production
npm run build

# preview production build locally
npm run preview
```
